# RAW decode contract

Status: the decoder runs. A synthetic 64×64 DNG generated by `tests/synthetic_dng.py` is what the tests open. That file is not a photograph. Real-camera RAW behavior is not validated.

## Dependency

RAW is off unless the optional extra is installed:

```sh
python -m pip install 'reality-first-photo[raw]'
```

That extra is `rawpy==0.26.1` (MIT). rawpy loads LibRaw. The wheel tested here reports LibRaw `0.22.0`. LibRaw is LGPL-2.1 or CDDL, at the user's choice. This repository does not vendor LibRaw, does not patch it, and does not build it. The binary inside the rawpy wheel is upstream rawpy's build, loaded by rawpy's extension. GPL demosaic packs (LMMSE, AMaZE, and the other pack algorithms) are not requested. Allowed demosaic names are `ahd` (default), `linear`, `vng`, and `ppg`.

Without the extra, a RAW file still fails the run before an output directory is created.

## What the pixels are

LibRaw is asked for 16-bit sRGB with `gamma=(1, 1)`, `no_auto_bright=True`, `bright=1`, highlight mode `Clip`, and `use_auto_wb=False`. Those 16-bit values are divided by 65535 and then encoded with the IEC 61966-2-1 sRGB transfer. The rest of the tool sees ordinary encoded-sRGB working pixels.

This is not a scene-referred spectral reconstruction. LibRaw's sRGB matrix is whatever that LibRaw build ships. `no_auto_scale` stays false, so LibRaw still scales black and white levels into the 16-bit range before we encode.

White balance, recorded in the manifest:

| `--raw-white-balance` | Behavior |
| --- | --- |
| `camera` (default) | As-shot camera multipliers. |
| `daylight` | LibRaw daylight balance (`use_camera_wb=False` and no user gains). |
| `custom` | `--raw-wb-gains R,G,B`. Green is copied to the second green. |

`--raw-half-size` emits one pixel per 2×2 block and skips interpolation. Orientation uses the file's flip value and records `RawUserFlip`.

## What is recorded

Each RAW item stores `RawContract` `raw-linear-srgb-iec-v1`, rawpy version, LibRaw version, the white-balance mode, the multipliers LibRaw reported, demosaic name, gamma, bit depth, highlight mode, matrix text, and decoded size. The run-level `raw` object repeats the requested settings.

## EXIF

Technical TIFF/DNG tags are copied when the container can be read: Make, Model, DateTime, ExposureTime, FNumber, ISO, FocalLength, LensModel, Orientation, WhiteBalance. JPEG and PNG exports write Make, Model, and DateTime into EXIF. TIFF exports write those three as TIFF ASCII tags. The manifest keeps the parsed technical tags as `PreservedExif`.

GPS and MakerNote are not read and not written. `ExifOmitted` is `GPS,MakerNote`. An external `exiftool` is not called.

Real-camera files used only as decode tests are listed in [RAW_TEST_SAMPLES.md](RAW_TEST_SAMPLES.md). They are CC0 samples from raw.pixls.us and are not stored in git.

## Not claimed

A successful RAW decode is not evidence of color accuracy, film similarity, or agreement with a camera manufacturer's JPEG.
